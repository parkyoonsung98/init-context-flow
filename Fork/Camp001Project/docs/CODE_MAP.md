## Runtime Script Folders

### `Assets/@Scripts/Manager`

- `GameManager.cs`: Runtime coordinator + event hub. Holds references to Player, Restaurant, UI. Manages spawning (workers/burgers/money/trash/guests) via PoolManager. Event bus: AddEventListener/BroadcastEvent. Auto-saves every 10s.
- `SaveManager.cs`: JSON save/load to persistentDataPath. Models: GameSaveData, RestaurantData, UnlockableStateData, QuestProgress.
- `PoolManager.cs`: Object pooling + Addressables async loading. Pop/Push interface for all spawnable entities.
- `Singleton.cs`: Generic singleton with lazy auto-creation.

### `Assets/@Scripts/System`

- `Restaurant.cs`: World root. Aggregates SystemBase modules and UnlockableBase props. Restores state from save. Runs CoDistributeWorkerAI() to assign idle workers to systems with jobs every 1s.
- `SystemBase.cs`: Base class for worker-assignable systems. Tracks assigned workers list.
- `MainCounterSystem.cs`: Core kitchen/front-desk automation. Three job types: MoveBurger, CounterCashier, CleanTable. Orchestrates worker coroutine job sequences.
- `Tutorial.cs`: Guides early progression through toast messages and forced unlock transitions. States: CreateFirstTable -> CreateIngredientStation_Bun -> CreateIngredientStation_Cheese -> Done.
- `TimedObjectBehavior.cs`: Generic timed process with optional worker-presence gating. Events: onTimeStart, onTimeEnd, onDurationProgress. Used by Grill, SinkStation.
- `ConstructionCostData.cs`: ScriptableObject for construction cost config.

### `Assets/@Scripts/System/Quest`

- `OldQuestSystem/`: Legacy custom quest framework (QuestJournal, QuestData, QuestUpdaterComponent, etc.). Still referenced but not primary.
- `Quest Machine System/`:
  - `QuestMachineManager.cs`: Singleton bridge to Pixel Crushers Quest Machine. Manages journal init and reward dispatch.
  - `QuestMachineQuestData.cs`: ScriptableObject wrapping Quest Machine quest + reward data. ID = asset name.
  - `QuestActionSetUnlockableState.cs`: Quest action that unlocks props via GameManager.
  - `QuestActionGiveReward.cs`: Quest action that triggers rewards via QuestMachineManager.
  - `XPRewardSystem.cs`: Reward system for XP grants.

### `Assets/@Scripts/Controllers`

- `Stickman/StickmanController.cs`: Base actor with NavMeshAgent movement, animation, tray, order bubble. Properties: OrderText, OrderCount, IsServing.
- `Stickman/WorkerController.cs`: Extends StickmanController. Adds coroutine job execution and system ownership (CurrentSystem). DoJob(IEnumerator).
- `Stickman/PlayerController.cs`: Extends WorkerController. Disables NavMeshAgent, uses CharacterController + joystick input. WASD in editor. 45-degree input rotation.
- `Stickman/GuestController.cs`: Extends StickmanController. States: None, Queuing, Serving, Eating, Leaving.
- `TrayController.cs`: Stack/carry behavior. DOJump animations for add/remove. GetIngredientCounts() for recipe matching. Physics-based visual stacking.
- `CameraController.cs`: Simple follow camera with offset.

### `Assets/@Scripts/Props`

#### `Props/Unlockable/`
- `UnlockableBase.cs`: State machine: Hidden -> ProcessingConstruction -> Unlocked. Integrates with construction UI and Quest Machine messages.
- `Counter.cs`: Guest queue management, recipe-based order generation, ingredient delivery validation (TryDeliverIngredientsFromTray), table routing, money spawning. Uses CleanPlatePile for plate gating.
- `Table.cs`: Guest seating/eating lifecycle (5-11s), trash/money generation, dirty state management.
- `Grill.cs`: Cooking state machine: Empty -> Cooking (10s) -> Cooked -> Burned (30s). Worker interaction for raw/cooked patty transfer.
- `Office.cs`: Opens employee upgrade popup on enter.
- `SinkStation.cs`: Dish cleaning via IngredientAbsorber + TimedObjectBehavior.
- `IngredientStation.cs`: Ingredient source. Auto-spawn loop or manual mode (nonAutomatic). Worker pickup with quest messaging.

#### `Props/Pile/`
- `PileBase.cs`: Stack container abstraction. Configurable grid (row x column). SpawnObject, RemoveFromPile, TrayToPile, PileToTray, DespawnObject. DOJump animations. Quest progress tracking.
- `BurgerPile.cs`: EObjectType.Burger pile.
- `MoneyPile.cs`: EObjectType.Money pile.
- `TrashPile.cs`: EObjectType.Trash pile.
- `IngredientPile.cs`: EObjectType.Ingredient pile. Initializes on Awake and OnEnable.
- `CleanPlatePile.cs`: Seeds initial clean plates (default 3). Accepts returned plates from tray.

#### `Props/Components/`
- `WorkerInteraction.cs`: Trigger-based callback system. Events: OnTriggerStart, OnInteraction (repeated at interval), OnTriggerEnd.

#### `Props/StationAttributes/`
- `IngredientStation.cs`: (listed under Unlockable above)
- `IngredientAbsorber.cs`: Consumes one matching tray ingredient by ID. Max input cap. OnIngredientAbsorbed callback.
- `IngredientPileAbsorber.cs`: Extends IngredientAbsorber. Takes items from source pile instead of tray.
- `IngredientData.cs`: ScriptableObject. Fields: prefab (Addressable), spawnInterval, maxSpawned. ID = asset name.
- `DatabasePile.cs`: ScriptableObject database for ingredient lookup. GetDataById, GetPrefabById, ContainsId.

#### `Props/Recipes/`
- `RecipeData.cs`: ScriptableObject. Fields: orderCategory (Main/Side/Drink), ingredients list, displayName.
- `DatabaseRecipeData.cs`: ScriptableObject collection of all available recipes.
- `CustomerOrderState.cs`: Runtime order tracking. Per-recipe ingredient delivery progress. TryDeliverIngredient, GetRemainingRecipeDisplayText (colored by category).
- `RecipeCrafter.cs`: Helper to cache recipe lookups by ID.

#### Other Props
- `Door.cs`: Opens/closes on worker proximity with DORotate animation.
- `TrashCan.cs`: Final trash disposal. Despawns items with jump animation.
- `TrayItemBehavior.cs`: Item metadata on tray objects. Fields: canBeTrash, data (IngredientData).

### `Assets/@Scripts/UI`

#### `UI/Popup/`

- `UI_Joystick.cs`: Mobile virtual joystick. Writes direction to GameManager.JoystickDir.
- `UI_UpgradeEmployeePopup.cs`: Employee upgrade popup shown from Office.
- `UI_UpgradeEmployeePopupItem.cs`: Individual upgrade item in popup.
- `UI_ToastMessage.cs`: Toast notification component.

#### `UI/WorldSpace/`
- `UI_ConstructionArea.cs`: Construction spending/progress UI. Deducts money per worker interaction tick. Slider + cost text.
- `UI_OrderBubble.cs`: World-space order text above guests.
- `UI_TimerProgress.cs`: Circular fill image for timed processes (cooking, washing).
- `UI_FaceCameraRotate.cs`: Billboard rotation for world-space UI.
